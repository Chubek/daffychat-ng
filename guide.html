DaffyChat Guide

Quick navigation and install instructions for the DaffyChat PWA.

1) Open and Join

  • Open DaffyChat Home.
  • Enter a shared Session code and Password.
  • Click Join.
  • Allow microphone permission when prompted.
  • Have the second user join with the same session/password.

2) During Call

  • Use Mute / Unmute for local mic control.
  • Watch Call state and status text for connection health.
  • Use Leave to disconnect cleanly.

3) Install as an App (PWA)

Install works best over HTTPS (or localhost during development).

  • Chrome / Edge (Desktop): open DaffyChat, click the install icon in the address bar, confirm Install.
  • Chrome (Android): open browser menu (⋮) → Install app / Add to Home screen.
  • Safari (iPhone/iPad): open Share sheet → Add to Home Screen.

4) Troubleshooting

  • If join fails with invalid password, verify both users use the same password.
  • If call has no audio, re-check microphone permission in browser settings.
  • If signaling disconnects, refresh and re-join the same session.
  • If browser shows ICE failed, configure reachable STUN/TURN in /etc/daffychat/daffychat.conf (avoid localhost for remote peers).
  • For restrictive NAT/mobile networks, set TURN (for example turns:turn.example.com:5349) with username/password.
  • DaffyChat does not require Google STUN; point STUN/TURN to your own reachable server or internal relay.
